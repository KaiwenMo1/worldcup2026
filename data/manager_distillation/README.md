# Manager Distillation Data

This directory stores the reviewable path from public manager evidence to app-compatible tactical skills.

```text
raw_evidence/{manager_id}/       Manually curated CSV claims and Markdown research
normalized_evidence/             Reserved for future normalized evidence snapshots
generated_skills/{manager_id}/   Generated SKILL.md, draft JSON, preview JSON, and validation report
```

Free-form Markdown is context only. Claims must be entered in structured CSV before they can pass validation or become executable tactical rules.
